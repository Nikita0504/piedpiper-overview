# PiedPiper Chat

> ⚠️ **Проект находится в активной разработке.** Большинство функций планируются к реализации. Клиентские приложения пока не разработаны.

Минималистичная платформа для общения, вдохновлённая Discord, с акцентом на лаконичный интерфейс, современный стек и расширяемость. Приложение предназначено для индивидуального общения, обмена сообщениями, звонков и базовой кастомизации профиля.

## 📋 Описание проекта

PiedPiper Chat — это децентрализованная система обмена сообщениями и видеовызовов, построенная на микросервисной архитектуре. Проект использует современный технологический стек на основе Kotlin и разработан с учётом масштабируемости и удобства разработки.

## ✨ Основные возможности (планируются)

### 1. Авторизация

- **Стандартная аутентификация** — вход по логину и паролю
- **OAuth интеграция** — вход через Google-аккаунт
- **Привязка аккаунтов** — возможность связать несколько способов входа для одного пользователя

### 2. Личные чаты

- **Индивидуальные беседы** — создание и управление приватными чатами между двумя пользователями
- **Статусы пользователей** — отображение текущего статуса (онлайн, не беспокоить и др.)
- **Минималистичный интерфейс** — упор на простоту и удобство использования
- **История сообщений** — сохранение и доступ к всей истории переписки

### 3. Звонки

- **Аудио- и видеозвонки** — между двумя участниками в личном чате
- **Плавное переключение режимов** — быстрое включение/выключение камеры и микрофона
- **Демонстрация экрана** — возможность делиться изображением экрана с собеседником
- **Stream с камеры** — передача видео с камеры устройства

### 4. Настройки и кастомизация профиля

- **Редактирование профиля** — изменение имени, статуса, аватара
- **Загрузка пользовательских изображений** — бесплатная возможность загружать свои картинки для оформления профиля
- **Просмотр результата** — предварительный просмотр оформления профиля до публикации
- **Поддержка анимированных аватаров** — возможность использовать GIF для анимированных профилей
- **Минимальные настройки** — функциональная приватность и управление уведомлениями

## 🏗️ Архитектура проекта

Проект состоит из микросервисов, каждый из которых отвечает за отдельную область функциональности:

### Микросервисы

- **[Auth Service](https://github.com/Nikita0504/piedpiper-auth-service)** — управление авторизацией, аутентификацией пользователей и OAuth интеграцией
- **[User Service](https://github.com/Nikita0504/piedpiper-user-service)** — управление профилями пользователей, статусами и настройками
- **[Chat Service](https://github.com/Nikita0504/piedpiper-chat-service)** — обработка личных сообщений, управление историей переписки и WebSocket соединениями

Каждый микросервис может масштабироваться независимо и имеет собственную базу данных.

## 🛠️ Технологический стек

| Категория | Технология | Описание |
|-----------|-----------|---------|
| **Язык** | Kotlin (KMP) | Общая кодовая база для серверной и клиентской логики |
| **Сервер** | Ktor | Асинхронный web-сервер на Kotlin |
| **Связь** | WebRTC, WebSocket | Для звонков, трансляций и обмена сообщениями |
| **Деплой** | Docker, Kubernetes | Контейнеризация и оркестрация |

### Почему такой стек?

- **Kotlin Multiplatform (KMP)** — позволяет использовать общий код между мобильными (Android/iOS), десктопными и веб-клиентами
- **Ktor** — лёгкий и расширяемый фреймворк для написания микросервисов на Kotlin
- **WebRTC** — стандарт для реализации аудио/видео-звонков и демонстрации экрана
- **WebSocket** — протокол для обмена сообщениями в реальном времени с низкой задержкой
- **Docker и Kubernetes** — обеспечивают масштабируемость, надежность и простоту развертывания
